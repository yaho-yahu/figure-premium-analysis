# 슬라이드 제작 계획 (v1 · 2026-10-16)

기준: `yaho.md`(제작 요구사항), `DESIGN.md`(디자인), 대상 = 데이터분석 입문 비전공자

## 1. 형식
- 직접 만드는 **단일 HTML 슬라이드덱** (16:9, 키보드/클릭 넘김, 슬라이드 진입 시 애니메이션 재생)
- 배포: `site/` 폴더를 별도 git 저장소로 → `gh`로 GitHub 저장소 생성 → **GitHub Pages**
  - 노트·레퍼런스·원본 데이터는 공개 저장소에 올리지 않음
- 이전 Claude Artifact 샘플은 디자인 참고용으로만 두고 사용하지 않음

## 2. 도구별 역할
| 도구 | 역할 | 결과물 |
|---|---|---|
| **anime.js** | 브라우저에서 움직이는 SVG 차트, 숫자 카운트업, 순차 등장 | HTML/JS (메인) |
| **manim** | 개념 설명 영상 (공식 조립, 회귀선이 맞춰지는 과정) | mp4/webm, 슬라이드에 자동재생 |
| **seaborn** | "예상 결과물 미리보기" 차트 (분포, 박스플롯) | PNG/SVG → anime.js로 등장 효과 |
| **Google Flow** (Claude in Chrome) | 표지 키비주얼, 피규어 유형 일러스트 | 이미지 에셋 |

⚠️ 아직 실제 데이터가 없으므로 모든 차트는 **시뮬레이션(가상) 데이터**이며 슬라이드에 `가상 데이터 · 개념 예시`로 표기
⚠️ 이미지 에셋은 저작권 문제를 피하기 위해 **실존 캐릭터가 아닌 오리지널 디자인**으로 생성
