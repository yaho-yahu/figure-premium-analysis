# 데이터분석 계획

## 1. 데이터 출처
| 구분 | 출처 | 용도 |
|---|---|---|
| 가격 | 스루가야(駿河屋) | 중고가 + 정가 |
| 가격 | 메루카리 / eBay (sold) | 실거래가 |
| 가격 | 번개장터 / 중고나라 | 국내 시세 (약관 확인 필요) |
| 메타 | MyFigureCollection | 정가, 출시일, 제조사, 한정 여부 |
| 인기 | Google Trends, MAL/AniList, Pixiv | 작품·캐릭터 인기 지표 |

## 2. 변수
- 종속: 프리미엄율
- 설명: 피규어 유형, 한정 여부, 재판 이력, 출시 후 경과 기간, 작품 인기, 캐릭터 인기, 제조사, 정가, 상태(미개봉/개봉)

## 3. 분석 절차
1. 수집·정제 (환율 통일, 이상치 제거)
2. EDA — 프리미엄율 분포, 유형·IP별 박스플롯
3. 그룹 비교 — 한정 vs 일반 (t-검정 / Mann-Whitney U)
4. 다중회귀 — log(프리미엄율) ~ 변수들
5. 사례 분석 — 재판·방영 발표 전후 가격 변화 2~3건

## 4. 예상 이슈와 대응
- **경품 피규어는 정가 없음** → 쿠지 1회가 / 출시 직후 시세를 기준가로 사용 (수집 시 결정)
- 호가 vs 실거래가 차이 → sold 데이터 우선
- 표본 수: 15개 그룹 × 20~30개 = 300~450건 목표. IP 선정 시 상품 수를 기준에 포함
- 상관 ≠ 인과, 생존 편향, 환율

## 5. 한계
- 인과 추론 불가 (인기 캐릭터라 한정판으로 출시됐을 가능성)
- 거래 기록이 없는 비인기 굿즈 누락
