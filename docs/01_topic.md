# 주제

## 제목 (가안)
서브컬쳐 피규어의 중고 프리미엄은 무엇이 만드는가?

## 배경
굿즈 중고 시장에서는 단종·한정판·인기 등의 이유로 정가보다 높은 가격(프리미엄)이 붙는다.
애니·게임 IP의 피규어를 대상으로 어떤 요인이 프리미엄과 관련 있는지 분석한다.

## 핵심 지표
**프리미엄율 = (중고 시세 − 정가) / 정가**

## 범위
- **1차**: 피규어 — 유형별(스케일 / 넨도로이드 / 경품) × 인기 IP 4~6개
- **확장(선택)**: 아크릴스탠드

## 가설
- H1. 한정판은 일반판보다 프리미엄율이 높다
- H2. 재판 발표 후 중고가는 하락한다
- H3. 애니 신작·후속 시즌 발표 후 관련 피규어 프리미엄이 상승한다
- H4. 같은 IP 내에서 캐릭터 인기가 높을수록 프리미엄이 높다
- H5. 단종 후 경과 기간이 길수록 프리미엄이 커진다
- (추가) 피규어 유형별로 프리미엄율 분포가 다르다
